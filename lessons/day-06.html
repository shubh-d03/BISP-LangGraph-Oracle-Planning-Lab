The big idea

This lesson connects language interpretation to controlled tools. A language model may recognize that a user wants a calculation, an integration or a pipeline. Structured output expresses that proposal using predictable fields. A tool definition describes an allowed capability and its inputs. Neither a valid-looking proposal nor a selected tool proves that an operation is authorized or that its target exists in Planning.

Follow the workflow

Consider the request, run Revenue Calculation. The model proposes a Business Rule operation and a name. The next boundary checks whether the operation is allowed. After that, the application still needs to validate the deployed name, required members, access and approval. Compare this with an unlisted action or a calculation request with no rule name. The first should stop as unsupported; the second should ask a question. The browser uses fixed teaching fixtures, not a live model.

If you are stuck

If you are stuck, separate classification from execution. First inspect a proposal without calling any Oracle tool. Make a small list of sample requests with expected operation labels and compare the model output with that list. Keep tool descriptions specific so a calculation is not confused with a data load. A schema checks the shape of a result, but real metadata and permissions must still be checked. Start with preview-only behavior.

02 / CLASS NOTES

Core concepts

Intent interpretation

A model interprets user intent; a tool definition specifies what it is allowed to call.

Tool descriptions

Clear tool descriptions reduce confusion between rules, integrations and pipelines.

Structured proposals

Structured output helps extract operation and parameters in a predictable shape.

Validation boundary

Treat model output as untrusted until validated against allowed operations and real metadata.

Oracle Planning context. A user asks to run a calculation. The model may propose business_rule, but the client must still validate the rule name and access before execution.
