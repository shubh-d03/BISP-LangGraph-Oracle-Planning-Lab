The big idea

Intent recognition asks what operation a user means. Tool selection maps that intended operation to a supported capability. A calculation request, an integration request and a pipeline request can sound similar in business conversation, but they need different tools. This lesson keeps selection visible and uses clarification when the request is ambiguous.

Follow the workflow

Compare the three concrete requests in the selector. Calculate revenue maps to the Business Rule tool. Load Actuals through an integration maps to the integration tool. A request naming a pipeline maps to the pipeline tool and its own variable schema. Now try, prepare the numbers. That wording is too vague to choose a write safely. Ask which operation the user intends. A selected tool still needs validated names, parameters, permissions and any required approval before dispatch.

If you are stuck

If you are stuck, create an expected-intent table using your own sample requests. Include near-synonyms and at least one ambiguous sentence. Compare the proposed operation with the expected label and inspect why a mismatch occurred. A single keyword is often insufficient. Keep the registry limited to actual supported tools. If the intent is unclear or the name is unregistered, return a selection or clarification result instead of invoking an arbitrary function.

day-13-example.py · Python
ALLOWED = {"business_rule", "data_integration", "pipeline", "substitution_variable"}

def validate_intent(intent: dict) -> dict:
    operation = intent.get("operation", "unsupported")
    if operation not in ALLOWED:
        return {"valid": False, "reason": "Unsupported operation"}
    return {"valid": True, "operation": operation,
            "requested_name": intent.get("name")}

# Parse with your configured LLM; validate before tool dispatch.
Explain this code
validate_intent checks an allowed label and preserves the requested name. It is a boundary check, not the classifier itself. Use a configured model for extraction and compare it with expected labels.
