The big idea

This lesson prepares the Python building blocks used later in the course. A function packages one behavior. A dictionary stores named values, such as an operation and its parameters. JSON is a text format used to exchange structured data. For now, keep everything local and use a mock result. The objective is to understand what enters a function and what it returns before adding an Oracle connection.

Open audio file

Follow the workflow

The sample handler receives an operation name and a parameter dictionary. For example, the operation is business rule, and the parameters identify Revenue Calculation. The handler returns a new dictionary containing those inputs and a clearly simulated queued status. Printing that dictionary only displays the result; it does not submit a job. Later, configuration such as the base URL and credentials belongs in the local Python environment, separate from shared course files.

If you are stuck

If you are stuck on the starter code, first call the function with a simple string and a small dictionary. Inspect the returned keys. Make sure you use return to send a value back to the caller; print alone does not do that. Do not add networking until this small test works. If configuration is missing later, report the setting name without displaying secret values. Python runs in your own notebook or editor, not inside this course page.
